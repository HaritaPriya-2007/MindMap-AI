# MindMap AI

MindMap AI is an AI-powered personalized learning assistant.

## Features

1. AI-generated concept maps
2. Personalized learning plans
3. Multiple-choice practice quizzes
4. Automatic quiz evaluation
5. Suggested learning resources
6. Downloadable JSON learning plans

## Technologies

- Python
- Streamlit
- Google Gemini API
- JSON
- python-dotenv

## Installation

Install Python 3.10 or newer.

Create virtual environment:

python -m venv .venv

Activate environment:

.venv\Scripts\activate

Install dependencies:

pip install -r requirements.txt

Run application:

streamlit run app.py

## Expected Result

The application generates a concept map,
a personalized study schedule and a quiz
based on the selected learning topic.
